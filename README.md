# Profil Muhammad Alfaraldi Raihan

Website profil pribadi. Dibuat dengan HTML, CSS, dan JavaScript biasa (tanpa framework).

## Struktur

```
.
├── index.html            # isi halaman
├── css/
│   └── style.css         # semua gaya tampilan
├── js/
│   └── main.js           # animasi scroll, zoom sertifikat, efek tombol
├── images/
│   ├── gerigi-2026.jpg
│   └── sertifikat-barunastra.jpg
└── README.md
```

## Menjalankan

Buka `index.html` di browser, atau aktifkan GitHub Pages lewat **Settings > Pages** (branch `main`, folder `/ (root)`).
